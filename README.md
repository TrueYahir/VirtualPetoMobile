# VirtualPeto Mobile Version

VirtualPeto is an Android application that allows users to create, manage, and spawn virtual pets on their screens. Built with Kotlin and Jetpack Compose, it features a library system to store animations, sounds, and custom metadata for each pet.

## Features
- **General Animations**: Manage you raw assets (images, GIFs, Video).
- **Smart Pet Creator:** A build-in editor to compile '.vpet' files by defining animations.
- **Pet Library:** View and launch your compiled '.vpet' files into a pet on your phone.

## Requirements
- Android SDK 28 or higher.
- Built using JetPack Compose preferences and manage internal folders.

## How to use
1. Import your assets via Library
2. Go to the Virtual Pet Creator Tab to assemble a new Pet.
3. Launch the pet from the Library tab.
